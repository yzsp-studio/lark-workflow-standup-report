## 🇬🇧 English

A schedule-and-to-do digest skill that chains calendar +agenda and task +get-my-tasks into one fixed workflow: fetch the agenda for a chosen date, fetch unfinished tasks, then have AI summarize both into a single schedule-and-open-work report. It removes the manual loop of scrolling a calendar, scrolling a task list, then typing a daily update by hand, and the output drops straight into a personal daily report or team standup. The skill documents its use cases, prerequisites, and a three-step workflow, and the date range can cover today, tomorrow, or this week.

### ✨ What it does

- Calls calendar +agenda to fetch the agenda for a given date
- Calls task +get-my-tasks to fetch unfinished to-dos
- AI merges schedule and open tasks into one digest
- Covers today, tomorrow, or this week
- A three-step workflow with stated prerequisites, reusable as-is
- Output is ready for a daily standup or personal daily report
